## 🎯 Getting Started

### Prerequisites

- C++ compiler (GCC, Clang, or MSVC)
- Basic knowledge of C++ and competitive programming

### Installation

```bash
# Clone the repository
git clone https://github.com/ms2150125-ui/CP_Using-CPP.git

# Navigate to the directory
cd CP_Using-CPP

# Compile and run any solution
g++ -o solution solution.cpp
./solution
```
